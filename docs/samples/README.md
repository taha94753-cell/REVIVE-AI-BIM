# Sample schedules (illustrative, not a real project)

Three small Primavera P6 exports to try the schedule analysis and progress updates:

1. Create a project with start date 2026-01-01 and a contract duration of 10 months.
2. Upload `clinic_baseline.xer` as the baseline schedule (cost- and resource-loaded, 13 activities).
3. On the Current delay sheet, upload `clinic_update_march.xer`, then `clinic_update_june.xer`, as progress updates.

Every figure in these files is made up to show the feature. Do not quote them as results.
